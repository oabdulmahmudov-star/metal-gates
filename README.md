# metal-gates
Bu sayt  buyurtma metall darvozalarni reklama qilish va darvoza ustalari bilan mijozlarni bog'lash uchun yaratilgan. Kimlar uchun Darvoza buyurtma qilmoqchi bo'lgan odamlar va hamkorlik qilmoqchi bo'lgan darvoza ustalari uchun.  Xususiyatlari Sayt telefonda ham, kompyuterda ham yaxshi ko'rinadi va Chrome'da tez ochiladi.
